Cloud compute

Google Cloud Batch / Compute Engine

Qué puede generar ScientificBrain →

ScientificBrain puede traducir un Physics Job validado a Google Cloud Batch. Batch aprovisiona la VM CPU/GPU, ejecuta una imagen de solver aprobada y deja resultados en Cloud Storage/Cloud Logging.

Comprobando Google Cloud…

Para enviar de verdad se deben configurar proyecto, bucket, perfiles de máquina/imagen y autenticación del servidor. La NVIDIA_API_KEY no es necesaria para Google Cloud Batch.
